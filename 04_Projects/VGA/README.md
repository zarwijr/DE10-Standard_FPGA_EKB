\# VGA Project for DE10-Standard (640x480@60Hz)



\## Overview

Fresh VGA project for Terasic DE10-Standard board using Cyclone V FPGA.

\- \*\*Resolution\*\*: 640×480 @ 60Hz (VESA standard)

\- \*\*Pixel Clock\*\*: 25.175MHz

\- \*\*Language\*\*: Verilog

\- \*\*Output Format\*\*: 8-bit RGB to ADV7123 DAC



\## File Structure

```

04\_Projects/VGA/

├── RTL/

│   ├── vga\_timing.v              # Sync \& pixel coordinate generator

│   └── color\_bar\_pattern.v       # 8-color bar pattern

├── Quartus/

│   ├── fpga\_vga.v                # Top-level module

│   ├── fpga\_vga.qsf              # Project settings (generated by Quartus)

│   └── pll\_25m175/               # PLL IP (must be created)

└── Simulation/

&#x20;   └── tb\_vga\_timing.v           # Testbench for vga\_timing

```



\## Setup Instructions



\### Step 1: Create PLL IP in Quartus

1\. Open Quartus → Tools → IP Catalog

2\. Search for "Altera PLL" (v16.1 or later)

3\. Configure:

&#x20;  - \*\*Input\*\*: refclk = 50MHz

&#x20;  - \*\*Output\*\*: outclk\_0 = 25.175MHz

&#x20;  - \*\*Output ports\*\*: refclk, rst, outclk\_0, locked

4\. Save as `pll\_25m175` in `04\_Projects/VGA/RTL/pll\_25m175/`

5\. Generate both `.qip` and `.v` files



\### Step 2: Create Quartus Project

1\. File → New Project

&#x20;  - Name: `fpga\_vga`

&#x20;  - Location: `04\_Projects/VGA/Quartus/`

&#x20;  - Device: 5CSXFC6D6F31C6N (Cyclone V)



2\. Add source files:

&#x20;  - RTL/vga\_timing.v

&#x20;  - RTL/color\_bar\_pattern.v

&#x20;  - Quartus/fpga\_vga.v

&#x20;  - RTL/pll\_25m175/pll\_25m175.qip



3\. Set Top-level Entity: `fpga\_vga`



\### Step 3: Pin Assignment

Use the `.qsf` file from board design or assign manually:

\- \*\*CLOCK\_50\*\*: PIN\_AF14

\- \*\*KEY\[0]\*\* (reset): PIN\_AJ4

\- \*\*VGA\_CLK\*\*: PIN\_AK21

\- \*\*VGA\_HS\*\*: PIN\_AK19

\- \*\*VGA\_VS\*\*: PIN\_AK18

\- \*\*VGA\_R\[7:0]\*\*: AK29-AJ26 (8 bits)

\- \*\*VGA\_G\[7:0]\*\*: AK26-AH23 (8 bits)

\- \*\*VGA\_B\[7:0]\*\*: AJ21-AK16 (8 bits)

\- \*\*VGA\_BLANK\_N\*\*: PIN\_AK22

\- \*\*VGA\_SYNC\_N\*\*: PIN\_AJ22



\### Step 4: Compile

1\. Processing → Start Compilation

2\. Check for errors (no warnings expected from design code)



\### Step 5: Program Board

1\. Tools → Programmer

2\. Select USB Blaster

3\. Add .sof file from output\_files/

4\. Start

\## Module Details



\### vga\_timing.v

Generates VGA synchronization signals and pixel coordinates.

\- \*\*Inputs\*\*: clk\_25m175 (25.175MHz), rst\_n (active-low)

\- \*\*Outputs\*\*:

&#x20; - `hsync`, `vsync`: Active-low sync signals

&#x20; - `pixel\_x`, `pixel\_y`: Current pixel coordinates (10-bit each)

&#x20; - `video\_on`: High during active display area (640×480)



\*\*Timing (640×480@60Hz)\*\*:

\- H: 640 active + 16 front + 96 sync + 48 back = 800 total

\- V: 480 active + 10 front + 2 sync + 33 back = 525 total

\- Frame time: (800 × 525) / 25.175MHz ≈ 16.68ms (60Hz)



\### color\_bar\_pattern.v

Simple test pattern: 8 vertical color bars (80 pixels each).

\- \*\*Colors\*\*: White, Yellow, Cyan, Green, Magenta, Red, Blue, Black

\- Outputs 8-bit RGB values based on `pixel\_x` and `video\_on`



\### fpga\_vga.v (Top-Level)

Integrates all blocks:

1\. \*\*PLL\*\*: 50MHz → 25.175MHz pixel clock

2\. \*\*vga\_timing\*\*: Generates sync \& coordinates

3\. \*\*color\_bar\_pattern\*\*: Produces test image

4\. \*\*DAC interface\*\*: Routes RGB to VGA connector

\## Testing

```bash

\# or manually:
```

Expected output:

\- Frame start messages every 16.68ms

\- pixel\_x wraps 0→799 each line

\- pixel\_y wraps 0→524 each frame

\- hsync pulses for 96 clocks (H\_DISPLAY + H\_FRONT)

\- vsync pulses for 2 lines (V\_DISPLAY + V\_FRONT)

2\. Press KEY\[0] to reset

\## Customization



To change color pattern, modify `color\_bar\_pattern.v`:

```verilog

// Example: Different width bars

if (pixel\_x < 100)     // 100-pixel wide bar

&#x20;   {vga\_r, vga\_g, vga\_b} = {8'hFF, 8'h00, 8'h00};  // Red

```



To change resolution to 800×600@60Hz:

1\. Update timing parameters in `vga\_timing.v`

2\. Reconfigure PLL to 40MHz instead of 25.175MHz

3\. Regenerate PLL IP

\## Troubleshooting



| Issue | Solution |

|-------|----------|

| Blank screen | Check VGA\_BLANK\_N polarity; should be active-low |

| Flickering | Verify PLL lock; check HSYNC/VSYNC timing |

| No image | Ensure PLL IP created and linked in .qsf |

| Timing errors | Verify 25.175MHz clock reaches all FF inputs |
